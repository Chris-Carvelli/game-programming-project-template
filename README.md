# Game Programming Project Template

Templeta repository to start working on your final project.

## Download
```sh
git clone --recurse-submodules https://github.com/Chris-Carvelli/game-programming-project-template.git
```
## Note about dependencies
If your project has any extra dependencies, add them in the `extra_dependencies` folder.

**PLEASE DO NOT ADD ANYTHING TO THE `lib` FOLDER**
